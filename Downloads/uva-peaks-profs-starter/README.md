# Peaks & Professors at UVA — Starter Website

A responsive static-site prototype inspired by the information architecture of Peaks & Professors at USC, redesigned for a UVA student organization.

## Run it locally in VS Code

1. Open the folder in VS Code.
2. Install the free **Live Server** extension by Ritwick Dey.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

You can also open `index.html` directly in a browser, although Live Server is easier while editing.

## File structure

- `index.html` — page content
- `styles.css` — all visual styling
- `script.js` — mobile navigation + prototype form message

## What to customize first

1. Organization name and launch copy
2. Real founding-team names/photos
3. Confirmed hike dates and trail information
4. Email / Instagram links
5. Real signup mechanism
6. UVA CIO disclaimer / policies / safety language
7. Your own outdoor photography

## Free hosting

### Option A — GitHub Pages
Best if you want the simplest possible static site tied to your GitHub repo.

Push these files to a public repository, then:
Settings → Pages → Build and deployment → Deploy from a branch → `main` / root.

### Option B — Netlify
Good if you want deployment previews and an easy path to forms.
Connect the GitHub repository in Netlify and publish the root directory.

### Option C — Cloudflare Pages
Also excellent for static hosting, especially if you later buy a custom domain.
